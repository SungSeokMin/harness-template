# backend 프로필 — 리뷰 체크리스트

- [ ] 모든 상태 변경이 허용된 전이를 거친다. 금지 전이는 UI가 아니라 코드에서 거부된다
- [ ] 함께 성공해야 하는 쓰기는 한 트랜잭션 안에 있고, 외부 사이드 이펙트는 그 안에서 실행되지 않는다
- [ ] 중복·동시 요청으로 중복 레코드, 이중 결제, 음수 잔액이 생기지 않는다
- [ ] 바뀐 상태·필드를 읽는 기존 코드가 모두 여전히 올바르게 동작한다
- [ ] 새로 생기거나 바뀐 모든 진입점에서 권한과 소유권을 서버가 확인한다
- [ ] 모든 입력이 검증되고, 에러는 명확한 메시지와 올바른 상태 코드로 반환된다
- [ ] 쿼리: N+1이 없고, 필요한 인덱스가 있고, 목록 조회에 상한(페이지네이션/limit)이 있다
- [ ] 스키마·데이터 변경이 배포 중에도 하위 호환되거나, 플랜에 배포 순서가 적혀 있다
- [ ] 로그와 에러 응답에 시크릿·토큰·개인정보가 없다
