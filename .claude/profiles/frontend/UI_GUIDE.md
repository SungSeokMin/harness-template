## 안티패턴 — 하지 않는다
| 하지 않는다 | 이유 |
|---|---|
| 글래스모피즘 (`backdrop-filter: blur`) | 생성된 템플릿의 가장 흔한 징후 |
| 그라데이션 텍스트 | 정보 없는 장식 |
| 기본값처럼 쓰는 보라/인디고 브랜드 색 | "AI = 보라색" 클리셰 |
| 모든 카드에 같은 큰 radius와 그림자 | 위계가 평평해진다 |
| 배경의 흐릿한 그라데이션 원 | 목적 없는 장식 |
| 모든 것을 가운데 정렬 | 훑어보기가 어려워진다. 기본은 왼쪽 정렬 |
