# frontend 프로필 — 리뷰 체크리스트

- [ ] 건드린 모든 화면에 로딩, 빈 상태, 에러, 성공 상태가 있다
- [ ] `docs/UI_GUIDE.md`의 토큰 밖에서 하드코딩한 색상·간격·글자 크기가 없다
- [ ] UI_GUIDE의 안티패턴을 새로 들여오지 않았다
- [ ] 변경 후 서버 데이터가 무효화·재조회되어, 성공한 동작 뒤에 오래된 화면이 남지 않는다
- [ ] 중복 제출이 막혀 있다 (버튼 비활성화 또는 요청 중복 제거)
- [ ] 키보드로 도달 가능하고, 포커스가 보이고, 입력 필드와 아이콘 버튼에 레이블이 있다
- [ ] 휴대폰 폭에서 가로 스크롤 없이 동작한다
- [ ] 클라이언트 코드에 시크릿이나 비공개 API 키가 없다
- [ ] 사용자에게 보이는 에러 메시지가 무슨 일이 있었고 무엇을 하면 되는지 알려 준다
- [ ] 변경된 화면을 실제로 렌더해 확인했다. 못 했다면 판정은 `미검증(이유)`이고, 최종 보고에 **미검증**으로 적는다 (도구는 프로젝트마다 다르다)
