# harness-template

AI 코딩 에이전트(Claude Code) 하네스의 공용 템플릿.
새 프로젝트를 시작할 때 이 저장소를 템플릿으로 복사하고, 프로젝트에서 넘어진 경험을 다시 이 템플릿으로 돌려보내 키운다.

## 사용법

1. GitHub에서 **Use this template → Create a new repository**
2. `CLAUDE.md`의 `<!-- TODO -->` 칸을 프로젝트에 맞게 채운다
3. 프로젝트에서 새로 생긴 규칙·칸 중 다른 프로젝트에도 쓸 만한 것은 이 저장소로 PR을 보낸다

## 하네스의 네 층

| 층 | 역할 | 위치 |
|---|---|---|
| 규칙 | 모든 작업에 항상 적용되는 약속 | `CLAUDE.md` |
| 순서표 | 특정 작업이 올 때만 펼치는 절차 | `.claude/skills/` |
| 역할 | 나눠 맡은 전문가, 작성자와 검증자 분리 | `.claude/agents/` |
| 울타리 | 기계가 강제하는 검사 | `.claude/hooks/`, 스크립트 |

## 성장 규칙

- 칸(섹션·규칙)을 추가할 때는 **유래**를 남긴다: `<!-- 유래: 무엇이 잘못됐었나 (프로젝트/PR) -->`
- 제약은 **참/거짓으로 판정 가능한 문장**으로 쓰고, 검증 주체(훅·테스트·리뷰어)를 적는다
- 아무도 걸리지 않는 칸은 지운다. 추가·삭제는 모두 `CHANGELOG.md`에 기록한다
